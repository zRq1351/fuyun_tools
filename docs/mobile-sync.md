# 手机同步使用指南

浮云剪贴板支持与 Android 手机互相同步剪贴板内容。**局域网直连，不经过任何服务器**——内容只在本机与你自己的手机之间传输。

## 功能模型

| 方向 | 方式 | 说明 |
|------|------|------|
| 电脑 → 手机 | 自动实时推送 | 电脑复制任意文本/图片，手机自动写入剪贴板并弹出通知 |
| 手机 → 电脑 | App 内主动发送 | 在手机 App 输入文本或选择图片，点发送即写入电脑剪贴板 |

> 为什么手机不能自动监听剪贴板？Android 10+ 系统只允许前台应用或默认输入法读取剪贴板，
> 这是系统级隐私限制。采用「App 内主动发送」是合法且可靠的方式，无需任何敏感权限。

## 电脑端设置

1. 打开浮云剪贴板 → 设置 → **手机同步**
2. 打开「启动同步服务」开关
3. 记下 **6 位配对码**（5 分钟内有效，一次性使用）
   - 如果手机与电脑在同一 Wi-Fi，App 会自动发现电脑，无需输地址
   - 否则记下「手动连接地址」（如 `http://192.168.1.100:45817`）

## 手机端使用

1. 安装同级目录 `fuyun_clipboard/`（D:////workspace////fuyun_clipboard）下的「浮云剪贴板」App（见下方构建说明）
2. 首次打开：
   - 在「发现的电脑」列表点选你的电脑（或手动输入地址）
   - 输入电脑上的 6 位配对码 → 点「配对」
3. 配对成功后进入主页：
   - **发送到电脑**：输入文本点「发送文本」，或点「发送图片」选图
   - **收到的内容**：电脑推送的内容自动写入剪贴板，并出现在列表中可一键复制

## 常见问题

**配对失败？**
- 确认手机与电脑在同一局域网（同一 WiFi/交换机）
- 确认电脑端同步服务已启动且配对码未过期（过期点「重新生成」）
- 防火墙如询问是否允许网络访问，请勾选「专用网络」

**连接中断？**
- App 会每 1~30 秒自动重连，无需手动操作
- 电脑重启后同步服务默认停止（可在设置页重新开启；开启过一次后会自动随设置页恢复）

**想换手机/吊销设备？**
- 电脑端设置 → 手机同步 → 「吊销设备」，旧手机立即失效，新手机重新配对

**安全说明**
- 所有接口均需设备令牌认证，配对码一次性有效
- 服务只监听局域网，内容不出本机网络
- 令牌保存在电脑本地数据目录，吊销即删除

## Android App 构建

环境要求：Android Studio（Ladybug 或更新）、JDK 17。

```bash
# 方式一：Android Studio 直接打开 android/ 目录（首次打开会自动生成 Gradle Wrapper）
# 方式二：命令行（需本机已安装 Gradle 8.9+）
cd ../fuyun_clipboard
gradle wrapper          # 首次生成 gradlew（已有脚本，仅缺 wrapper jar）
./gradlew assembleDebug # 产出 app/build/outputs/apk/debug/app-debug.apk
```

技术栈：Kotlin + Jetpack Compose + OkHttp（HTTP/WebSocket）+ 原生 NSD（mDNS 发现）。
最低支持 Android 8.0（API 26）。

## 协议简表（开发者参考）

| 端点 | 方法 | 认证 | 说明 |
|------|------|------|------|
| `/api/pair` | POST | 配对码 | 换取设备令牌 |
| `/api/status` | GET | 无 | 电脑名称/配对状态 |
| `/api/clip` | POST | 令牌 | 手机 → 电脑（text / image） |
| `/api/history` | GET | 令牌 | 增量拉取历史 |
| `/api/image` | GET | 令牌 | 下载图片二进制 |
| `/api/ws` | WS | 令牌 | 实时推送频道 |

服务类型：`_fuyun._tcp.`（mDNS），默认端口 45817（占用时自动顺延）。
