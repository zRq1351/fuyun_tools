## 关键修复与改进

### 安全性修复

| 问题 | 严重性 | 位置 | 修复 |
|------|--------|------|------|
| `unsafe { File::from_raw_fd(...).read_exact(&mut buf) }` — 双重释放风险 | 高 | OCR engine | 使用 `OwnedFd` + `File::from()` 安全构造 |
| `format!("sqlite:{}", path)` — SQL 注入路径 | 中 | document_database | 已验证路径来源为内部，但建议后续添加路径规范化 |
| API key 明文存储 | 中 | config.rs | 当前设计合理（本地应用），但建议后续考虑 OS keychain 集成 |

### 内存与性能修复

| 问题 | 影响 | 修复方案 |
|------|------|----------|
| 文档模块 FTS 索引每次查询重建 | O(n) 查询退化 | 添加 `Arc<Mutex<FtsIndex>>` 缓存 |
| 屏幕录制双重快照 | 帧时间翻倍 | 合并为单次快照 + 共享引用 |
| 前端应用列表每次渲染全量排序 | O(n log n) 无谓开销 | 添加 `useMemo` 排序缓存 |
| 剪贴板 guard 15s 超时 | 状态不一致窗口过大 | 降至 3s |
| 进程内存指标 `as f64` 精度丢失 | 大值显示错误 | 改用 `as u64` |
