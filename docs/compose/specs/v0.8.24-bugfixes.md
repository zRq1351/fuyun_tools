## [S2] Design

### S2.1 skipNextClick 残留

**场景：** 用户在 ClipboardList 或 ImageClipboardList 中拖拽卡片，鼠标移到 carousel-stage 区域外松手。此时 `onStageMouseUp` 设 `skipNextClick = true`，但 click 事件不在 stage 上触发，导致标志无法被 `onStageClick` 消费。后续任意一次点击被静默吞掉。

**修复：** `onStageMouseUp` 中设 `skipNextClick = true` 后，加一个 `setTimeout` 在下一个 tick 重置该标志，确保即使 click 事件没有触发，下一次 click 也不会受影响。

### S2.2 navRepeatTimer ID 复用

**场景：** `startNavRepeat` 中 `navRepeatTimer` 先赋值为 `setTimeout` 返回值，400ms 后被 `setInterval` 覆盖。`stopNavRepeat` 同时调用 `clearInterval` 和 `clearTimeout`，逻辑不够清晰。

**修复：** 拆分为 `navRepeatDelayId`（setTimeout）和 `navRepeatIntervalId`（setInterval），各自在 `stopNavRepeat` 中用对应的清除方法。ImageClipboardList 额外补上缺失的 `navRepeatDir = 0` 重置。

### S2.3 README 版本号

**修复：** 将 `README.md` 和 `README_EN.md` 中的版本号更新为 `0.8.22`。
