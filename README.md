fuyun_tools 是一款常驻系统托盘的桌面效率工具，聚焦四件事：

- **剪贴板管理**：高效记录和管理文字与图片剪贴板历史
- **AI 划词助手**：在 Windows 上进行智能翻译与解释
- **截图与 OCR**：快捷截图并提取图片中的文字
- **录屏功能**：支持系统音频与麦克风采集的专业录屏

核心定位：

- 一套快捷键，统一管理文字与图片剪贴板
- 一条划词链路，完成翻译、解释与复制
- 一条截图与 OCR 链路，支持从截图到文字提取
- 一条录屏链路，支持胶囊控制、音频采集与录制参数配置
- 一组可配置策略，平衡历史容量与关键内容保留

同时，本项目本身也采用了 AI 全流程开发模式：从需求拆解、方案设计、编码实现到文档维护，均由 AI 深度参与。

## ✨ 功能概览

### 📋 剪贴板管理

- **自动记录**：实时捕获剪贴板变更，支持快速回填到任意应用
- **智能搜索**：支持关键词搜索，快速定位历史记录
- **分类管理**：自定义分类标签，按场景归档重要内容
- **置顶保护**：重要条目可置顶，不受容量限制影响
- **双路径操作**：支持键盘（方向键、回车）与鼠标（滚轮、点击）操作
- **AI 集成**：窗口内直接使用 AI（`T` 翻译 / `E` 解释）
- **右键菜单**：一键"翻译/解释"当前选中条目
- **语言配置**：自定义翻译目标语言与解释语言
- **统一标识**：文本与图片剪贴板底层使用 item_id，切换体验更流畅

### 🖼️ 图片剪贴板管理

- **自动识别**：检测剪贴板中的图片，自动生成缩略图列表
- **智能搜索**：支持按分类和关键词搜索图片历史
- **快速回填**：双击缩略图直接粘贴到当前光标位置
- **大图预览**：全屏查看图片细节，支持缩放和平移
- **持久化存储**：图片历史与分类本地保存，重启后可继续使用
- **磁盘管理**：可配置图片存储上限（默认 2GB），自动清理旧图片
- **性能优化**：异步生成预览，修复长列表滚动卡顿问题

### 🔎 图片 OCR（Windows）

- **固定窗口 OCR**：在固定图片窗口中右键触发 OCR 识别
- **独立结果展示**：识别结果在专用文本窗口显示，支持复制
- **Windows 原生**：基于 Windows Media OCR API，无需联网
- **适用平台**：目前仅支持 Windows 10/11

### 🎥 录屏（Windows）

- **悬浮胶囊**：轻量级录屏控制栏，支持快捷键唤起
- **一键控制**：开始、暂停、恢复、停止，操作简单直观
- **音频采集**：
    - 系统音频输出（基于 WASAPI 原生采集链路）
    - 麦克风设备选择，支持多设备切换
    - 录制过程中实时切换麦克风（快捷键 `Ctrl+Space`）
- **参数配置**：
    - 帧率：1-120 FPS（默认 30）
    - 视频码率：500-50000 kbps（默认 6000）
    - 音频码率：32-512 kbps（默认 160）
    - 光标录制：可选是否捕获鼠标指针
    - 工具栏保护：可选择是否隐藏录屏胶囊
- **区域选择**：支持全屏或指定窗口录制
- **ffmpeg 管理**：首次启用时自动检测并按需下载，显示实时进度
- **状态保护**：功能停用时胶囊显示禁用状态，防止误触发
- **音频优化**：修复录制麦克风时系统音频消失问题，优化停止逻辑

### 🔤 AI 划词助手（Windows）

- **多场景选词**：支持拖拽、双击、三击等多种文本选择方式
- **智能弹出**：选中文本后自动显示划词工具栏
- **核心功能**：
    - 翻译：将选中文本翻译为目标语言
    - 解释：用通俗易懂的语言解释专业内容
    - 复制：快速复制选中文本
    - 自定义提示词：支持添加个性化 AI 指令
- **流式输出**：结果窗口实时显示 AI 生成的内容
- **一键回写**：支持复制并自动粘贴到原文位置
- **网络搜索**：可选 Bing 搜索引擎快速查找相关内容

### 🤖 AI 服务配置

- **内置提供商**：
    - DeepSeek：高性能对话模型
    - 通义千问（qwen）：阿里大语言模型

- **自定义扩展**：支持添加任意 OpenAI 兼容接口的自定义提供商
- **便捷管理**：下拉选项中直接删除自定义提供商
- **安全存储**：API Key 存储在系统凭据管理器（keyring），加密保存
- **连接测试**：配置后可立即验证连通性
- **提示词模板**：自定义翻译和解释的系统提示词（Prompt）

### ⚙️ 系统集成

- **常驻托盘**：最小化到系统托盘，不占用任务栏空间
- **开机自启**：支持配置随系统启动自动运行

## 🚀 快速开始

### 1. 启动应用

运行 fuyun_tools 后，图标将显示在系统托盘区。右键点击托盘图标可访问菜单。

### 2. 使用全局热键

- **文字剪贴板**：`Ctrl+Shift+Z` - 打开文字剪贴板历史窗口
- **图片剪贴板**：`Ctrl+Shift+X` - 打开图片剪贴板历史窗口
- **截图**：`Ctrl+Shift+S` - 启动截图工具
- **录屏**：`Ctrl+Shift+R` - 唤起录屏胶囊（需先在设置中启用）

### 3. 配置 AI 服务

进入「设置 → AI 设置」：

1. **选择提供商**：
    - 内置：DeepSeek / 通义千问 / 小米 Mimo
    - 自定义：添加任意 OpenAI 兼容接口
2. **填写配置**：API 地址、模型名称和密钥
3. **连接测试**：点击“连接测试”按钮验证配置有效性
4. **保存设置**：测试通过后保存配置

### 4. 体验划词功能

在 Windows 任意应用中选中文本：

1. **自动弹出**：选中后立即显示「划词工具栏」
2. **选择操作**：点击 [翻译] 或 [解释]
3. **查看结果**：在「结果窗口」中查看流式输出
4. **一键回写**：点击回写按钮，自动复制并粘贴到原文位置

### 5. 体验录屏功能

进入「设置 → 录屏」，启用录屏功能：

1. **首次启用**：自动检测并按需下载 ffmpeg（显示实时进度）
2. **唤起胶囊**：使用快捷键 `Ctrl+Shift+R` 或从设置页打开
3. **配置音频**：在胶囊设置中选择系统音频/麦克风设备
4. **调整参数**：设置帧率、码率等录制参数
5. **开始录制**：点击开始按钮，录制过程中可使用 `Ctrl+Space` 切换麦克风

## 🧭 使用说明

### 剪贴板窗口

**打开方式**：快捷键 `Ctrl+Shift+Z` 或从托盘菜单打开

- **导航操作**：
    - `← / →` 方向键切换历史条目
    - `Enter` 回填选中内容到当前光标位置
    - `Esc` 关闭窗口
- **滚动控制**：鼠标滚轮上下滚动历史列表
- **AI 快捷操作**：
    - 选中条目后按 `T` - 翻译为配置的目标语言
    - 选中条目后按 `E` - 用配置的语言解释
- **分类管理**：
    - 右键点击条目可设置分类标签
    - 支持创建自定义分类
    - 已分类项目不受容量限制（当启用“仅限制未分组项”时）
- **置顶功能**：重要条目可置顶，永久保留
- **界面交互**：拖拽顶部「调高」手柄可调整窗口垂直位置
- **高级功能**：点击「调高」手柄与搜索框之间的空白区域，可展开/收起 AI 语言设置面板

### 图片剪贴板窗口

**打开方式**：快捷键 `Ctrl+Shift+X` 或从托盘菜单打开

- **选择图片**：单击缩略图卡片进行选中
- **快速粘贴**：双击卡片直接回填到当前光标位置
- **浏览大图**：点击右上角「全屏」按钮查看大图预览
    - 支持鼠标滚轮缩放
    - 支持拖拽平移
    - 按 `Esc` 退出预览
- **管理历史**：点击右上角「删除」图标移除记录
- **批量操作**：
    - `← / →` 浏览图片
    - `Enter` 粘贴当前项
    - `Delete` 删除当前项
- **分类搜索**：支持按分类筛选和关键词搜索

### 固定图片 OCR（Windows）

**使用流程**：

1. **截图或复制图片**：使用截图工具或直接复制图片
2. **固定图片**：图片会自动显示在固定窗口中
3. **触发 OCR**：在固定图片窗口中右键，选择「OCR 识别」
4. **查看结果**：识别结果在独立 OCR 文本窗口显示
5. **复制使用**：可直接复制识别后的文本

**特点**：

- 基于 Windows Media OCR API，无需联网
- 支持中英文等多种语言
- 目前仅支持 Windows 10/11

### 上限策略（文字 + 图片）

**访问路径**：设置 → 剪贴板 → 上限策略

**两种模式**：

1. **智能保护模式**（推荐）：
    - 开启「仅限制未分组项」
    - 所有已分类、置顶的内容不受容量限制影响
    - 只清理未分类的普通历史记录
    - 适合长期使用，重要内容永不丢失

2. **全面清理模式**：
    - 关闭「仅限制未分组项」
    - 历史上限将作用于所有记录（包括重要项目）
    - 超出限制后按时间顺序清理最旧的记录
    - 适合定期清理所有历史的场景

**容量配置**：

- 文字剪贴板：可配置最大条目数（默认 50）
- 图片剪贴板：可配置最大条目数（默认 50）和磁盘占用上限（默认 2GB）

### 划词工具栏（Windows）

**触发条件**：在任意应用中完成文本选中操作

**使用流程**：

1. **选中文本**：拖拽、双击或三击选择文本
2. **工具栏弹出**：自动显示在选中文本附近
3. **选择操作**：
    - [翻译] - 将文本翻译为目标语言
    - [解释] - 用通俗语言解释内容
    - [复制] - 复制选中文本
    - [自定义] - 执行自定义 AI 指令（如配置了）
4. **查看结果**：点击后立即在「结果窗口」展示 AI 生成的流式输出
5. **回写原文**：点击结果窗口的回写按钮，自动复制并粘贴
6. **关闭工具栏**：点击工具栏外部或按 `Esc` 键

**高级功能**：

- 支持添加自定义提示词模板
- 可配置网络搜索（Bing）
- 支持修饰键触发（可选）

### 录屏胶囊（Windows）

**打开方式**：启用录屏后通过快捷键 `Ctrl+Shift+R` 或设置页唤起

**核心控制**：

- **开始录制**：点击开始按钮或按下快捷键
- **暂停/恢复**：录制过程中可随时暂停和恢复
- **停止录制**：点击停止按钮，视频自动保存到指定目录
- **取消录制**：取消后不保存任何文件

**音频路由**：

- **系统音频**：捕获电脑播放的声音（游戏、音乐等）
- **麦克风**：录制外部声音（解说、会议等）
- **设备选择**：可在胶囊设置中选择具体的音频设备
- **实时切换**：录制过程中点击麦克风图标或使用 `Ctrl+Space` 快速开关

**参数配置**：

- **帧率**：1-120 FPS（默认 30，越高越流畅但文件越大）
- **视频码率**：500-50000 kbps（默认 6000，影响画质）
- **音频码率**：32-512 kbps（默认 160，影响音质）
- **光标录制**：可选择是否显示鼠标指针
- **工具栏保护**：可选择是否在视频中隐藏录屏胶囊

**区域选择**：

- **全屏录制**：捕获整个屏幕
- **窗口录制**：选择特定窗口进行录制

**首次依赖检查**：

- 自动检测 `ffmpeg.exe` 是否存在
- 缺失时引导按需下载并显示实时进度
- 下载地址可自定义（默认从 Gitee 下载）

**停用态保护**：

- 录屏功能停用时胶囊显示禁用状态
- 阻止误触发，避免无效操作

### AI 配置建议

- **安全存储**：API密钥通过系统凭据管理器(keyring)加密保存，永不明文存储
- **连接验证**：务必使用「连接测试」按钮验证配置有效性后再保存
- **自定义扩展**：支持添加任意OpenAI兼容接口，灵活对接私有化部署模型
- **提示词模板**：可在设置中修改翻译/解释的系统提示词(Prompt)，实现个性化输出

## ❓ 常见问题

### 1) 为什么 Linux/macOS 没有划词功能？

当前版本仅在 Windows 完成了划词链路实现；Linux/macOS 暂不支持，正在开发中。

### 2) 自定义提供商怎么删除？

在 AI 提供商下拉框中，对应自定义项右侧点击 `X` 即可删除。内置提供商（DeepSeek、通义千问、小米 Mimo）不可删除。

### 3) 保存设置后关闭窗口偶发延迟？

已针对关闭流程做响应优化，建议更新到最新版本。如仍遇到延迟，可尝试重启应用。

### 4) 为什么启用录屏时会提示下载 ffmpeg？

首次启用录屏时，应用会检查预期 `bin` 路径下是否存在 `ffmpeg.exe`；若缺失，会引导按需下载。这是为了减小安装包体积，用户可按需获取。

### 5) 录制过程中如何快速切换麦克风？

启用录屏后，可使用以下两种方式切换麦克风：

- **点击图标**：点击录屏胶囊上的麦克风图标
- **快捷键**：使用 `Ctrl+Space`（可在设置中自定义）

按下快捷键时麦克风开启，松开时关闭，适合临时解说场景。

### 6) 剪贴板历史记录滚动卡顿怎么办？

该问题已在 v0.6.77 版本中修复。请确保使用最新版本。如果仍有卡顿，可尝试：

- 减少历史条目数量上限
- 清理旧的历史记录
- 检查图片存储上限是否过高

### 7) API Key 安全吗？

非常安全。API Key 存储在系统凭据管理器（keyring）中，加密保存，不会明文写入配置文件。即使查看配置文件也看不到完整的密钥。

### 8) 如何备份和恢复数据？

进入「设置 → 备份与恢复」：

- **自动备份**：可配置定期自动备份（每日/每周/每月）
- **手动备份**：点击“立即备份”创建备份文件
- **恢复数据**：选择备份文件进行恢复
- **备份内容**：包括剪贴板历史、图片历史、分类标签、AI 配置等

## 🏗️ 技术架构

### 前端技术栈

- **框架**：Vue 3 + Composition API
- **UI 组件库**：Element Plus
- **图标库**：Lucide Vue Next + Element Plus Icons
- **构建工具**：Vite
- **状态管理**：Vue Reactive + Composables

### 后端技术栈

- **桌面框架**：Tauri 2.x
- **编程语言**：Rust
- **AI SDK**：async-openai（OpenAI 兼容接口）
- **数据库**：SQLite（通过 sqlx）
- **图像处理**：image + imageproc
- **音频采集**：WASAPI（Windows Audio Session API）
- **录屏引擎**：Windows Graphics Capture + ffmpeg

#### 2. 图片剪贴板 (`services/image_clipboard_manager`)

#### 3. AI 服务 (`services/ai_services`)

- 流式响应处理
- 多提供商支持

#### 4. 划词助手 (`features/text_selection`)

- 鼠标事件监听
- 文本选择检测
- 工具栏智能定位
- 结果窗口流式输出

## 🔐 数据安全与隐私

### API Key 安全

- **加密存储**：使用 Windows Credential Manager（keyring）加密存储
- **不落地**：不会明文写入任何配置文件
- **掩码显示**：界面中仅显示部分字符，保护密钥安全

### 本地数据

- **历史记录**：存储在应用数据目录的 SQLite 数据库中
- **图片文件**：单独的图片存储目录，可配置上限
- **配置文件**：JSON 格式，不包含敏感信息
- **日志文件**：仅在调试模式下生成，发布版不写入日志

### 隐私保护

- **离线可用**：OCR 功能完全离线，无需联网
- **自主选择**：AI 功能需要联网，但用户可自主选择提供商
- **无数据收集**：应用不收集任何用户数据
- **开源透明**：代码完全开源，可审计
