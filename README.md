# 🚀 fuyun_tools

[中文](README.md) | [English](README_EN.md)

fuyun_tools 是一款常驻系统托盘的桌面效率工具，聚焦四件事：

- 更高效地管理剪贴板历史
- 在 Windows 上进行 AI 划词翻译与解释
- 在 Windows 上进行快捷截图与图片 OCR 识别
- 在 Windows 上进行录屏与音频采集

核心定位：

- 一套快捷键，统一管理文字与图片剪贴板
- 一条划词链路，完成翻译、解释与复制
- 一条截图与 OCR 链路，支持从截图到文字提取
- 一条录屏链路，支持胶囊控制、音频采集与录制参数配置
- 一组可配置策略，平衡历史容量与关键内容保留

同时，本项目本身也采用了 AI 全流程开发模式：从需求拆解、方案设计、编码实现到文档维护，均由 AI 深度参与。

---

## ✨ 功能概览

### 📋 剪贴板管理

- 自动记录剪贴板历史，支持快速回填
- 支持搜索、分类、删除和历史容量上限配置
- 支持键盘与鼠标双路径操作（方向键、回车、滚轮等）
- 支持在剪贴板窗口内直接使用 AI（`T` 翻译 / `E` 解释）
- 支持右键菜单一键“翻译/解释”当前条目
- 支持配置翻译目标语言与解释语言

### 🖼️ 图片剪贴板管理

- 自动识别并记录剪贴板中的图片，生成缩略图列表
- 支持图片搜索与分类管理，便于按场景归档
- 支持双击快速回填图片到当前文档输入位置
- 支持大图预览，便于查看图片细节
- 图片历史与分类会持久化保存，本地重启后可继续使用

### 🔎 图片 OCR（Windows）

- 固定图片窗口支持右键触发 OCR 识别
- 识别结果会在独立文本窗口展示，支持复制使用
- OCR 能力目前仅在 Windows 可用

### 🎥 录屏（Windows）

- 新增录屏悬浮胶囊，支持快捷键唤起与一键开始/暂停/恢复/停止
- 支持系统音频输出与麦克风设备选择（基于原生 WASAPI 采集链路）
- 支持帧率、视频码率、音频码率、光标录制等参数配置
- 首次启用录屏会自动检查 `ffmpeg.exe`，缺失时按需下载并显示实时进度
- 录屏功能停用时会在胶囊中直接展示停用状态，避免误触发

### 🔤 AI 划词助手（Windows）

- 支持拖拽、双击、三击等选词场景
- 自动弹出划词工具栏，可直接翻译/解释/复制
- 结果窗口支持流式输出，阅读反馈更及时
- 结果窗口支持一键回写到原应用（复制并自动粘贴）

### 🤖 AI 服务配置

- 内置 DeepSeek / 通义千问（qwen）/ 小米 Mimo（xiaomimimo）
- 支持新增任意 OpenAI 兼容自定义提供商
- 支持在下拉选项中直接删除自定义提供商
- API Key 存储在系统凭据管理器（keyring）

### ⚙️ 系统集成

- 常驻托盘，支持开机自启
- 全局热键：文字剪贴板 / 图片剪贴板 / 截图
- 深浅色主题切换
- 内置应用更新能力

### 🧠 AI 全流程开发

- 需求分析与任务拆解由 AI 辅助完成
- 代码实现、重构与问题修复由 AI 持续迭代
- 中英文文档与使用说明由 AI 同步维护

## 🚀 快速开始

1. **启动应用**：运行 fuyun_tools 后，图标将显示在系统托盘区
2. **使用全局热键**：
    - 文字剪贴板：Windows `Ctrl+Shift+Z`
    - 图片剪贴板：Windows `Ctrl+Shift+X`
    - 截图：Windows `Ctrl+Shift+S`
3. **配置AI服务**：进入「设置 → AI 设置」
    - 选择内置提供商（DeepSeek/通义千问/Mimo）或添加自定义OpenAI兼容接口
    - 填写API地址、模型名称和密钥
    - 点击连接测试确保配置有效
4. **体验划词功能**：在Windows任意应用中选中文本
    - 自动弹出「划词工具栏」，点击[翻译]或[解释]
    - 查看流式输出的「结果窗口」，支持一键回写到原文位置
5. **体验录屏功能**：进入「设置 → 录屏」，启用录屏后使用录屏胶囊开始录制
    - 首次启用会自动检测并按需下载 ffmpeg
    - 可在胶囊设置中选择系统音频/麦克风设备并调整录制参数

## 🧭 使用说明

### 剪贴板窗口

- **导航操作**：`← / →` 切换条目，`Enter` 回填
- **滚动控制**：鼠标滚轮上下滚动历史列表
- **AI快捷操作**：选中条目后按 `T` 翻译 / `E` 解释
- **界面交互**：拖拽顶部「调高」手柄可调整窗口垂直位置
- **高级功能**：点击「调高」手柄与搜索框之间的空白区域，可展开/收起AI语言设置面板

### 图片剪贴板窗口

- **选择图片**：单击缩略图卡片进行选中
- **快速粘贴**：双击卡片直接回填到当前光标位置
- **浏览大图**：点击右上角「全屏」按钮查看大图预览
- **管理历史**：点击右上角「删除」图标移除记录
- **批量操作**：`← / →` 浏览图片，`Enter` 粘贴当前项

### 固定图片 OCR（Windows）

- **触发方式**：在固定图片窗口中右键，选择 OCR 识别
- **结果展示**：识别结果在独立 OCR 文本窗口显示
- **适用平台**：目前仅支持 Windows

### 上限策略（文字 + 图片）

- **访问路径**：设置 → 剪贴板 → 上限策略
- **智能保护**：开启「仅限制未分组项」时，所有已分类/置顶的内容不受容量限制影响
- **全面清理**：关闭后，历史上限将作用于所有记录（包括重要项目）

### 划词工具栏（Windows）

- **触发条件**：在任意应用中完成文本选中操作
- **功能按钮**：提供[翻译]、[解释]、[复制]三个核心操作
- **智能响应**：点击后立即在「结果窗口」展示AI生成的流式输出
- **界面控制**：点击工具栏外部或ESC键即可收起

### 录屏胶囊（Windows）

- **触发方式**：启用录屏后可通过录屏快捷键或设置页唤起胶囊
- **核心控制**：支持开始、暂停、恢复、停止录制
- **音频路由**：可在胶囊设置中选择系统音频输出与麦克风设备
- **首次依赖检查**：自动检测 `ffmpeg.exe`，缺失时引导按需下载并显示实时进度
- **停用态保护**：录屏功能停用时胶囊会显示停用状态并阻止误触发

### AI 配置建议

- **安全存储**：API密钥通过系统凭据管理器(keyring)加密保存，永不明文存储
- **连接验证**：务必使用「连接测试」按钮验证配置有效性后再保存
- **自定义扩展**：支持添加任意OpenAI兼容接口，灵活对接私有化部署模型
- **提示词模板**：可在设置中修改翻译/解释的系统提示词(Prompt)，实现个性化输出

## ❓ 常见问题

### 1) 为什么 Linux/macOS 没有划词功能？

当前版本仅在 Windows 完成了划词链路实现；Linux/macOS 暂不支持，正在开发中。

### 2) 自定义提供商怎么删除？

在 AI 提供商下拉框中，对应自定义项右侧点击 `X` 即可删除。

### 3) 保存设置后关闭窗口偶发延迟？

已针对关闭流程做响应优化，建议更新到最新版本。

### 4) 为什么启用录屏时会提示下载 ffmpeg？

首次启用录屏时，应用会检查预期 `bin` 路径下是否存在 `ffmpeg.exe`；若缺失，会引导按需下载。
