# 剪贴板功能与交互体验优化计划

## 1. 目标与成功标准
- **目标**：优化目前文本和图片剪贴板的快捷键切换体验，并修复划词检测与手动复制 (`Ctrl+C`) 的冲突。
- **成功标准**：
  1. 能够通过数字键 `Ctrl+1~9` 快速粘贴前 9 项历史记录。
  2. 修复划词后立即手动 `Ctrl+C` 导致内容未能进入剪贴板历史的问题。
  3. 当打开文本剪贴板时，按下图片剪贴板快捷键能自动关闭文本剪贴板并打开图片剪贴板，反之亦然。

## 2. 当前状态分析
- **剪贴板窗口切换**：全局快捷键处理中（`src-tauri/src/lib.rs`），如果检测到某个剪贴板已经打开，对应的快捷键直接 `return` 而没有互相切换的逻辑。
- **划词与手动 Ctrl+C 冲突**：划词检测机制（`src-tauri/src/features/text_selection.rs`）在检测到鼠标释放后，会临时禁用剪贴板监听器并模拟 `Ctrl+C`，完成后再恢复原本的剪贴板内容。如果用户此时手动按下 `Ctrl+C`，由于监听器被禁用且内容被旧快照覆盖，导致手动复制的内容丢失。
- **快捷键快速填充**：前端 Vue 组件中，键盘事件监听只处理了方向键和回车键，没有处理数字键快速选择。

## 3. 提议的变更
### 3.1. 修复手动 Ctrl+C 的冲突
- **文件**: `src-tauri/src/features/mouse_listener.rs`
  - **修改**: 在低级键盘钩子中捕获 C 键（`VK_C` / `0x43`）的按下事件，如果此时 `Ctrl` 键也处于按下状态，则触发一个记录标记。
- **文件**: `src-tauri/src/features/text_selection.rs`
  - **修改**: 增加 `MANUAL_CTRL_C_TIME` 全局时间戳记录，并提供 `mark_manual_ctrl_c` 方法。在划词检测结束后，如果检测到最近发生过手动 `Ctrl+C`，则**跳过恢复剪贴板旧快照的步骤**，并将最新内容主动添加到剪贴板历史 `clipboard_manager.add_to_history(text)` 中。

### 3.2. 剪贴板窗口的互相切换
- **文件**: `src-tauri/src/lib.rs`
  - **修改**: 修改文本和图片剪贴板快捷键注册逻辑：
    - 当按下文本剪贴板快捷键时，如果图片剪贴板正在显示，则先隐藏图片剪贴板，再显示文本剪贴板。
    - 当按下图片剪贴板快捷键时，如果文本剪贴板正在显示，则先隐藏文本剪贴板，再显示图片剪贴板。

### 3.3. 支持 Ctrl+数字键快速填充
- **文件**: `src/pages/clipboard/App.vue` & `src/pages/image_clipboard/App.vue`
  - **修改**: 在全局 `keydown` 事件监听中增加逻辑，如果按下 `Ctrl` 和 `1~9` 的数字键，则获取对应索引（`0~8`）的历史记录，并调用填充方法 (`selectAndFillDirect` / `fillById`)。

## 4. 假设与决策
- **决策**：对于手动 `Ctrl+C` 的判断，我们假设只要在划词检测（耗时极短，< 1秒）期间或刚刚结束时，检测到了低级键盘钩子的 `Ctrl+C` 物理按键事件，即认为用户的真实意图是手动复制。因此放弃恢复划词前状态，从而保证用户的手动复制不会丢失。
- **假设**：`isInputLikeTarget` 能够正确排除用户在搜索框中输入 `Ctrl+C` 时的意外触发。

## 5. 验证步骤
1. **测试窗口切换**：打开文本剪贴板，按下图片剪贴板快捷键，确认文本窗口消失，图片窗口出现。
2. **测试手动复制**：选中文本后立刻按下 `Ctrl+C`，确认此时剪贴板列表中新增了刚才选中的内容。
3. **测试数字键粘贴**：打开剪贴板，按下 `Ctrl+1`，确认第一条内容被自动回填。
